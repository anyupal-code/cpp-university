# Урок 3. Условия, `switch`, циклы `while` / `for`, `break`, `continue`

## Цель

Научиться управлять ходом выполнения программы: выбирать ветку
по условию, повторять действия, досрочно выходить из циклов.

## Ключевые понятия

- **Условие** — выражение типа `bool`.
- **Ветвление** — выбор одного из путей выполнения.
- **Цикл** — повторение блока операторов.
- **Итерация** — одно выполнение тела цикла.
- **`break` / `continue`** — прерывание и пропуск итерации.

---

## 1. `if` / `else` / `else if`

```cpp
if (условие) {
    // выполняется, если условие истинно
} else if (другое_условие) {
    // если первое ложно, а второе истинно
} else {
    // если все условия ложны
}
```

**Пример:**

```cpp
int x;
std::cin >> x;

if (x > 0) {
    std::cout << "Положительное\n";
} else if (x < 0) {
    std::cout << "Отрицательное\n";
} else {
    std::cout << "Ноль\n";
}
```

**Фигурные скобки** — обязательны, даже если одна строка. Это правило
защищает от ошибок при изменении кода.

**Условия в C++:**

- `=` — присваивание, `==` — сравнение.
- `0` — ложь, всё остальное — истина.
- В C++ **неявное приведение к `bool`** есть, но лучше писать явно:
  `if (x != 0)` вместо `if (x)`.

## 2. Логические операторы

| Оператор | Что делает |
|---|---|
| `&&` | И (оба истинны) |
| `\|\|` | Или (хотя бы один истинен) |
| `!` | Не (инверсия) |

**Сравнения:** `==`, `!=`, `<`, `>`, `<=`, `>=`.

```cpp
if (x > 0 && x < 10) {
    std::cout << "0 < x < 10\n";
}
```

**Короткое замыкание:** если первый операнд `&&` ложен — второй
**не вычисляется**. Это важно:

```cpp
if (p != nullptr && p->value > 0) {
    // безопасно: если p == nullptr, второе не выполняется
}
```

---

## 3. Тернарный оператор `?:`

Краткая форма `if-else`:

```cpp
условие ? значение_если_истина : значение_если_ложь
```

```cpp
int a = 5, b = 7;
int max = (a > b) ? a : b;    // max = 7

std::cout << (x > 0 ? "плюс" : "минус или ноль");
```

**Не злоупотребляйте.** Если выражение длинное или вложенное — используйте `if-else`.

## 4. `switch`

Выбор по значению целочисленного типа (или `enum`, `char`):

```cpp
switch (choice) {
    case 1:
        std::cout << "Один\n";
        break;
    case 2:
        std::cout << "Два\n";
        break;
    case 3:
    case 4:
        std::cout << "Три или четыре\n";
        break;
    default:
        std::cout << "Другое\n";
}
```

- **`case`** — метка, сравнивается с значением.
- **`break`** — выйти из `switch`. Без него выполнение «проваливается» в следующий `case` (**fall-through**).
- **`default`** — если ни один `case` не подошёл.
- Значения `case` — **константы времени компиляции**.

**Fall-through иногда полезен:**

```cpp
switch (c) {
    case 'a':
    case 'e':
    case 'i':
    case 'o':
    case 'u':
        std::cout << "Гласная\n";
        break;
    default:
        std::cout << "Согласная\n";
}
```

**Внимание:** в C++17+ есть атрибут **`[[fallthrough]]`** — пометка,
что провал намеренный. Компилятор не выдаёт предупреждение.

```cpp
case 1:
    std::cout << "Один\n";
    [[fallthrough]];
case 2:
    std::cout << "Не два, но связан с первым\n";
    break;
```

## 5. Цикл `while`

Проверка **до** тела. Если условие сразу ложно — тело не выполнится.

```cpp
while (условие) {
    // тело
}
```

```cpp
int i = 0;
while (i < 5) {
    std::cout << i << " ";
    ++i;
}
```

**Опасность:** бесконечный цикл, если условие никогда не станет ложным.

---

## 6. Цикл `do-while`

Проверка **после** тела. Тело выполнится **минимум один раз**.

```cpp
do {
    // тело
} while (условие);   // ← точка с запятой обязательна
```

```cpp
int x;
do {
    std::cout << "Введите число > 0: ";
    std::cin >> x;
} while (x <= 0);
```

Часто используется для **валидации ввода**.

---

## 7. Цикл `for`

```cpp
for (инициализация; условие; шаг) {
    // тело
}
```

```cpp
for (int i = 0; i < 5; ++i) {
    std::cout << i << " ";
}
```

Порядок выполнения:

1. `инициализация` — один раз.
2. `условие` — проверка перед каждой итерацией.
3. тело.
4. `шаг` — после тела.

**Несколько счётчиков:**

```cpp
for (int i = 0, j = 10; i < j; ++i, --j) {
    std::cout << i << " " << j << "\n";
}
```

**Бесконечный:**

```cpp
for (;;) {
    // выход через break
}
```

---

## 8. Range-based `for` (C++11)

Обход всех элементов контейнера:

```cpp
int arr[] = {1, 2, 3, 4, 5};

for (int x : arr) {
    std::cout << x << " ";
}
```

По ссылке (для изменения):

```cpp
for (int& x : arr) {
    x *= 2;
}
```

По константной ссылке (без копирования):

```cpp
for (const auto& x : arr) {
    std::cout << x << " ";
}
```

Работает для `vector`, `string`, `map` и любых контейнеров с `begin` / `end`.

## 9. `break` и `continue`

- **`break`** — немедленный выход из **ближайшего** цикла или `switch`.
- **`continue`** — переход к следующей итерации.

```cpp
for (int i = 0; i < 10; ++i) {
    if (i == 5) break;        // выход на 5
    std::cout << i << " ";
}
// 0 1 2 3 4

for (int i = 0; i < 10; ++i) {
    if (i % 2 == 0) continue; // пропустить чётные
    std::cout << i << " ";
}
// 1 3 5 7 9
```

**Не путайте:** `break` внутри `switch` выходит только из `switch`,
не из внешнего цикла.

## 10. Типичные задачи

### Сумма чисел от 1 до N

```cpp
int sum = 0;
for (int i = 1; i <= n; ++i) {
    sum += i;
}
```

### Проверка простого числа

```cpp
bool is_prime(int n) {
    if (n < 2) return false;
    for (int i = 2; i * i <= n; ++i) {
        if (n % i == 0) return false;
    }
    return true;
}
```

### Ввод до нуля

```cpp
int x, sum = 0;
while (std::cin >> x && x != 0) {
    sum += x;
}
```

### FizzBuzz

```cpp
for (int i = 1; i <= 100; ++i) {
    if (i % 15 == 0)      std::cout << "FizzBuzz\n";
    else if (i % 3 == 0)  std::cout << "Fizz\n";
    else if (i % 5 == 0)  std::cout << "Buzz\n";
    else                  std::cout << i << "\n";
}
```

### Таблица умножения

```cpp
for (int i = 1; i <= 9; ++i) {
    for (int j = 1; j <= 9; ++j) {
        std::cout << i * j << "\t";
    }
    std::cout << "\n";
}
```

## 11. Частые ошибки

- **`=` вместо `==`** в условии — присваивание, а не сравнение.
  ```cpp
  if (x = 5) { /* всегда истина, x перезаписан! */ }
  ```
- **Забыли `break`** в `switch` — нежелательный fall-through.
- **Точка с запятой после `while (условие);`** — пустое тело цикла:
  ```cpp
  while (i < 5);   // бесконечный цикл, тело пустое
  ```
- **Изменение счётчика внутри `for`** — плохая практика:
  ```cpp
  for (int i = 0; i < 10; ++i) {
      i += 2;   // сбивает логику
  }
  ```
- **`break` в `switch` внутри цикла** — выходит из `switch`, а не из цикла.
- **Сравнение `unsigned` с `int`** — знаковое превращается в беззнаковое.
- **Бесконечный `while`** — забыли изменить переменную условия.
