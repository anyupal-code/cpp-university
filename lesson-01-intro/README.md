# Урок 1. Введение. Первая программа. Ввод-вывод. Память и типы данных

## Цель

Познакомиться с языком C++, понять структуру программы, научиться
компилировать и запускать её, освоить базовый ввод-вывод и типы данных.

## Ключевые понятия

- **Компилируемый язык** — исходник превращается в машинный код
  до запуска.
- **Статическая типизация** — тип переменной известен на этапе компиляции.
- **Точка входа** — функция `main`, с неё начинается программа.
- **`#include`** — подключение заголовочного файла.
- **Пространство имён `std`** — где живут `cout`, `cin`, `string` и т.д.
- **`;`** — конец оператора (обязательна).

---

## 1. Структура программы

```cpp
#include <iostream>   // подключаем ввод-вывод

int main() {          // точка входа
    std::cout << "Hello, World!" << std::endl;
    return 0;         // 0 — успешное завершение
}
```

Разбор:

- **`#include <iostream>`** — заголовок для `std::cout`, `std::cin`.
- **`int main()`** — функция, с которой начинается программа.
- **`std::cout << ...`** — вывод в консоль.
- **`std::endl`** — перевод строки + сброс буфера.
- **`return 0;`** — код возврата (0 — успех).

## 3. Вывод

```cpp
std::cout << "Текст";
std::cout << "Число: " << 42 << "\n";
std::cout << "Строка" << std::endl;
```

- **`<<`** — оператор вывода, можно объединять несколько значений.
- **`"\n"`** — перевод строки (быстрее, чем `std::endl`).
- **`std::endl`** — перевод строки + очистка буфера.

---

## 4. Ввод

```cpp
int x;
std::cin >> x;               // читает целое

std::string name;
std::cin >> name;            // читает одно слово

std::getline(std::cin, name); // читает всю строку до Enter
```

- **`>>`** — оператор ввода.
- **`std::cin >>`** останавливается на пробеле.
- **`std::getline`** читает всю строку.

**Важно:** если после `cin >> x` использовать `getline`, останется
символ новой строки в буфере. Нужно «съесть» его:

```cpp
std::cin >> x;
std::cin.ignore();          // пропустить оставшийся Enter
std::getline(std::cin, s);
```

## 5. Типы данных

| Тип | Размер | Диапазон |
|---|---|---|
| `bool` | 1 байт | `true` / `false` |
| `char` | 1 байт | -128..127 |
| `short` | 2 байта | -32768..32767 |
| `int` | 4 байта | ±2 млрд |
| `long long` | 8 байт | ±9·10¹⁸ |
| `float` | 4 байта | ~7 знаков точности |
| `double` | 8 байт | ~15 знаков точности |

**Беззнаковые:** `unsigned int`, `unsigned char` и т.д.

**Размер типа:**

```cpp
std::cout << sizeof(int) << "\n";        // обычно 4
std::cout << sizeof(double) << "\n";     // обычно 8
```

## 6. Переменные и присваивание

```cpp
int x = 5;               // инициализация
double pi = 3.14;
bool flag = true;
char c = 'A';
std::string s = "text";
```

**Списковая инициализация (рекомендуется):**

```cpp
int x{5};
double pi{3.14};
```

Она запрещает «сужающие» преобразования:

```cpp
int x{3.14};   // ошибка компиляции — предупреждает
int x = 3.14;  // компилируется, но x = 3 — сюрприз
```

**`auto`** — вывести тип автоматически:

```cpp
auto x = 5;          // int
auto pi = 3.14;      // double
```

## 7. Арифметика

| Операция | Знак |
|---|---|
| Сложение | `+` |
| Вычитание | `-` |
| Умножение | `*` |
| Деление | `/` |
| Остаток | `%` |
| Инкремент | `++` |
| Декремент | `--` |

**Важно:** целочисленное деление отбрасывает дробную часть.

```cpp
int a = 7 / 2;         // 3
double b = 7.0 / 2;    // 3.5
int c = 7 % 2;         // 1
```

**Приведение типов:**

```cpp
double d = 7 / 2;                        // 3.0 — сначала целое деление
double d = 7 / 2.0;                      // 3.5
double d = static_cast<double>(7) / 2;   // 3.5
```

## 8. Константы

```cpp
const int MAX = 100;      // значение нельзя менять
constexpr int N = 10;     // вычисляется на этапе компиляции
```

- **`const`** — запрет изменения.
- **`constexpr`** — гарантированно известно на этапе компиляции,
  эффективнее.

## 9. Пример: сложение двух чисел

```cpp
#include <iostream>

int main() {
    int a, b;
    std::cout << "Введите два числа: ";
    std::cin >> a >> b;

    int sum = a + b;
    std::cout << "Сумма: " << sum << "\n";
    return 0;
}
```

## 10. Частые ошибки

- **Забыли `;`** в конце оператора — ошибка компиляции.
- **Забыли `std::`** перед `cout` / `cin` / `string` — ошибка.
- **Использование `=` вместо `==`** в условиях (будет в уроке 3).
- **`int x = 3.14;`** — компилируется, но теряет дробную часть.
  Используйте `int x{3.14};` — тогда ошибка.
- **`cin >> s` вместо `getline`** — читает только до пробела.
- **Забыли `cin.ignore()`** после `cin >> x` перед `getline` —
  получите пустую строку.
