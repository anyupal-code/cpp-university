## Задача 1. Уникальные элементы и дубликаты

**Условие.** Дан массив целых. Найти:

1. Все уникальные значения.
2. Все значения, встречающиеся больше одного раза.
3. Количество уникальных.

**Идея.**

- **`std::set`** — уникальные + отсортированные автоматически.
- **`std::unordered_map<int, int>`** — частота каждого.
- **`std::unordered_set`** — быстрая проверка «видели ли».

**Что использовать:** `unordered_map` — за один проход считаем частоты.
Уникальные — ключи. Дубликаты — ключи с частотой ≥ 2.

**Сложность:** O(n).

**Разбор** — в [task_duplicates.cpp](task_duplicates.cpp).

## Задача 2. Группировка слов по длине

**Условие.** Дан текст. Сгруппировать слова по длине. Вывести группы
в порядке возрастания длины, слова внутри — по алфавиту.

**Идея.**

- **`std::map<int, std::vector<std::string>>`** — ключ = длина,
  значение = слова.
- `map` сортирует по длине автоматически.
- Внутри каждой группы — `std::sort` + `std::unique`.

**Почему `map`, не `unordered_map`:**
- Нужен **отсортированный** обход по длине.
- `unordered_map` пришлось бы сортировать отдельно.

**Сложность:** O(n log n).

**Разбор** — в [task_grouping.cpp](task_grouping.cpp).

## Задача 3. Сортировка студентов

**Условие.** Дан список студентов (имя, возраст, средний балл).
Сортировать по:

1. Среднему баллу (по убыванию).
2. При равенстве — по возрасту (по возрастанию).
3. При равенстве — по имени (по возрастанию).

**Идея.** Одна сортировка с **многокритериальным компаратором**.

**Способ 1:** лямбда с каскадом условий.

```cpp
std::sort(v.begin(), v.end(), [](const Student& a, const Student& b) {
    if (a.avg != b.avg) return a.avg > b.avg;
    if (a.age != b.age) return a.age < b.age;
    return a.name < b.name;
});
```

**Способ 2 (C++20, ranges):** кортеж для сравнения.

```cpp
std::ranges::sort(v, std::less{}, [](const Student& s) {
    return std::tuple{-s.avg, s.age, s.name};
});
```

**Рекомендация:** способ 1 — понятнее, способ 2 — короче.
В курсе используем оба.

**Разбор** — в [task_sort_students.cpp](task_sort_students.cpp).

## Задача 4. Two Sum

**Условие.** Дан массив и целевое число `target`. Найти **индексы**
двух элементов, сумма которых равна `target`. Решение единственное.

**Наивное решение:** два вложенных цикла — O(n²).

**Эффективное:** `unordered_map<int, int>` — за один проход.

**Идея:**

- Идём по массиву слева направо.
- Для каждого `x` проверяем: есть ли в `map` число `target - x`?
- Если есть — нашли пару.
- Иначе — сохраняем `x` с его индексом.

**Сложность:** O(n) в среднем.

**Почему `unordered_map`, не `map`:**
- Порядок не нужен.
- O(1) против O(log n).

**Разбор** — в [task_two_sum.cpp](task_two_sum.cpp).

## Задача 5. Статистика текста

**Условие.** Дан текст. Найти:

1. Количество слов.
2. Количество уникальных слов.
3. Топ-5 самых частых слов с частотами.

**Идея.**

- `std::unordered_map<std::string, int>` — частоты.
- Топ-5 — либо `partial_sort`, либо `priority_queue`.

**Почему `unordered_map`:**
- Считаем частоты — порядок не важен.
- Для топ-5 сортируем отдельно.

**Важно:** регистр и знаки препинания — нормализовать.

**Разбор** — в [task_text_stats.cpp](task_text_stats.cpp).

## Как выбирать контейнер под задачу

| Что нужно | Контейнер |
|---|---|
| Уникальные, порядок не важен | `unordered_set` |
| Уникальные, отсортированные | `set` |
| Частоты, порядок не важен | `unordered_map` |
| Частоты, сортировка по ключу | `map` |
| Группировка по ключу | `map<K, vector<V>>` |
| Быстрый поиск «есть ли» | `unordered_set` |
| Пара «индекс → значение» | `unordered_map` |

## Как выбирать алгоритм

| Задача | Алгоритм |
|---|---|
| Сортировка | `sort`, `stable_sort` |
| Топ-K | `partial_sort`, `nth_element`, `priority_queue` |
| Поиск | `find`, `find_if` |
| Подсчёт | `count`, `count_if` |
| Преобразование | `transform`, `views::transform` |
| Фильтрация | `copy_if`, `erase_if`, `views::filter` |
| Сумма / произведение | `accumulate` |

## Советы к КР

1. **Выбирай контейнер осознанно.** Не «vector по умолчанию».
2. **Используй `<algorithm>`.** Не пиши циклы, где есть готовая функция.
3. **`unordered_*` быстрее**, если порядок не важен.
4. **Компаратор** — строгий (`<`, не `<=`).
5. **Тестируй на границах:** пустой ввод, один элемент, дубликаты.
6. **Пиши понятно.** Баллы дают и за частичное решение.
