# Урок 2. Память и типы данных. IEEE 754. Битовые операции

## Цель

Понять, как данные хранятся в памяти, чем отличаются целые и вещественные
типы, как работают битовые операции и почему важно знать их особенности.

## Ключевые понятия

- **Байт** — минимальная адресуемая единица памяти (8 бит).
- **Бит** — 0 или 1.
- **Размер типа** — сколько байт занимает значение (`sizeof`).
- **Диапазон** — минимум и максимум значений типа.
- **IEEE 754** — стандарт хранения вещественных чисел.
- **Битовые операции** — `&`, `|`, `^`, `~`, `<<`, `>>`.

---

## 1. Бит, байт, размеры

- 1 байт = 8 бит.
- `char` = 1 байт, `int` обычно 4 байта, `double` обычно 8 байт.
- Точные размеры — через `sizeof(тип)`.

```cpp
#include <iostream>

int main() {
    std::cout << "bool:        " << sizeof(bool) << " байт\n";
    std::cout << "char:        " << sizeof(char) << " байт\n";
    std::cout << "short:       " << sizeof(short) << " байт\n";
    std::cout << "int:         " << sizeof(int) << " байт\n";
    std::cout << "long:        " << sizeof(long) << " байт\n";
    std::cout << "long long:   " << sizeof(long long) << " байт\n";
    std::cout << "float:       " << sizeof(float) << " байт\n";
    std::cout << "double:      " << sizeof(double) << " байт\n";
    std::cout << "long double: " << sizeof(long double) << " байт\n";
    return 0;
}
```

**Размеры в байтах — не гарантированы стандартом.** `int` обычно 4, но
на некоторых платформах — 2 или 8. Гарантия только по минимальным размерам:

| Тип | Минимум |
|---|---|
| `char` | 1 байт |
| `short` | 2 байта |
| `int` | 2 байта |
| `long` | 4 байта |
| `long long` | 8 байт |

## 2. Знаковые и беззнаковые

```cpp
int          a = -100;     // знаковый
unsigned int b = 100;      // беззнаковый
```

- **Знаковые** (`int`, `long long`, `char`) — могут быть отрицательными.
- **Беззнаковые** (`unsigned int`, `unsigned char`) — только ≥ 0.

**Важно:** размер тот же, но диапазон сдвигается.

| Тип | Диапазон |
|---|---|
| `int` (4 байта) | −2 147 483 648 … 2 147 483 647 |
| `unsigned int` (4 байта) | 0 … 4 294 967 295 |

**Диапазоны — через `<limits>`:**

```cpp
#include <iostream>
#include <limits>

int main() {
    std::cout << "int max:          " << std::numeric_limits<int>::max() << "\n";
    std::cout << "int min:          " << std::numeric_limits<int>::min() << "\n";
    std::cout << "unsigned int max: " << std::numeric_limits<unsigned int>::max() << "\n";
    std::cout << "long long max:    " << std::numeric_limits<long long>::max() << "\n";
    return 0;
}
```

**Переполнение:**

```cpp
int x = std::numeric_limits<int>::max();
x++;   // неопределённое поведение для знакового int
```

Для `unsigned` переполнение **определено** — циклический переход:

```cpp
unsigned int y = 0;
y--;   // y = 4 294 967 295 (максимум)
```

## 3. IEEE 754 — как хранятся вещественные числа

Стандарт **IEEE 754** описывает хранение `float` (32 бита) и `double` (64 бита)
в виде:

```
[ знак | экспонента | мантисса ]
```

**Для `float` (32 бита):**

| Часть | Биты | Что означает |
|---|---|---|
| Знак | 1 | 0 — плюс, 1 — минус |
| Экспонента | 8 | порядок, со сдвигом 127 |
| Мантисса | 23 | дробная часть |

**Для `double` (64 бита):**

| Часть | Биты |
|---|---|
| Знак | 1 |
| Экспонента | 11 |
| Мантисса | 52 |

**Следствия:**

1. **Не все числа представимы точно.** `0.1` в двоичной системе — бесконечная
   дробь, хранится **приближённо**.

   ```cpp
   double a = 0.1 + 0.2;
   std::cout << (a == 0.3) << "\n";   // 0 (ложь!)
   ```

2. **Ограниченная точность.** У `float` — около 7 знаков, у `double` — около 15.

3. **Специальные значения:** `+∞`, `-∞`, `NaN` (не число).

**Сравнение вещественных:**

```cpp
#include <cmath>

bool nearly_equal(double a, double b, double eps = 1e-9) {
    return std::fabs(a - b) < eps;
}
```

**Правило:** вещественные числа сравнивайте **с точностью**, не через `==`.

## 4. Битовые операции

| Операция | Знак | Что делает |
|---|---|---|
| И | `&` | 1, если оба бита 1 |
| Или | `\|` | 1, если хотя бы один бит 1 |
| Исключающее или | `^` | 1, если биты разные |
| Не | `~` | инвертирует все биты |
| Сдвиг влево | `<<` | сдвигает биты влево |
| Сдвиг вправо | `>>` | сдвигает биты вправо |

**Пример с числами:**

```
a = 12 = 1100
b = 10 = 1010

a & b  = 1000 = 8
a | b  = 1110 = 14
a ^ b  = 0110 = 6
~a     = ...11110011 = -13 (для знакового int)
```

**Проверка бита:**

```cpp
bool is_bit_set(unsigned x, int pos) {
    return (x >> pos) & 1u;
}
```

**Установка бита:**

```cpp
x |= (1u << pos);
```

**Сброс бита:**

```cpp
x &= ~(1u << pos);
```

**Инверсия бита:**

```cpp
x ^= (1u << pos);
```

## 5. Сдвиги

```cpp
1 << 0   // 1
1 << 1   // 2
1 << 2   // 4
1 << 10  // 1024
```

- **`<<` — умножение на 2ⁿ.**
- **`>>` — деление на 2ⁿ** (для беззнаковых; для знаковых — зависит от знака).

**Осторожно:**

- Сдвиг на **размер типа или больше** — неопределённое поведение.
- `<<` для **отрицательных** — UB до C++20.

**В C++20+ `<<` определён для знаковых** — но в курсе работаем
с беззнаковыми для сдвигов.

## 6. Практическое применение

### Хранение флагов в одном числе

```cpp
const unsigned FLAG_READ    = 1u << 0;
const unsigned FLAG_WRITE   = 1u << 1;
const unsigned FLAG_EXECUTE = 1u << 2;

unsigned perms = FLAG_READ | FLAG_WRITE;

if (perms & FLAG_READ) { /* можно читать */ }
perms |= FLAG_EXECUTE;   // добавить право
perms &= ~FLAG_WRITE;    // убрать право
```

### Быстрая проверка чётности

```cpp
bool is_odd = x & 1u;
```

### Степени двойки

```cpp
bool is_power_of_two(unsigned x) {
    return x != 0 && (x & (x - 1)) == 0;
}
```

## 7. Частые ошибки

- **Сравнение `double` через `==`** — почти всегда неверно.
- **Переполнение знакового `int`** — UB, а не «переход в минус».
- **Смешивание знаковых и беззнаковых** в выражениях — приводит
  к неожиданным результатам.
  ```cpp
  int a = -1;
  unsigned b = 1;
  if (a < b) { /* ложь! a превращается в огромное unsigned */ }
  ```
- **Сдвиг на размер типа или больше** — UB.
- **`sizeof` возвращает `size_t`** — беззнаковый тип. Сравнение
  с `int` может дать сюрпризы.
