# Урок 4. Функции. Рекурсия. Перегрузка

## Цель

Научиться разбивать программу на функции: передавать параметры,
возвращать значения, использовать значения по умолчанию, перегружать
функции и писать рекурсивные алгоритмы.

## Ключевые понятия

- **Функция** — именованный блок кода, который можно вызывать.
- **Прототип** — объявление функции до её использования.
- **Параметр** — переменная в заголовке функции.
- **Аргумент** — значение, передаваемое при вызове.
- **Возврат** — результат через `return`.
- **Перегрузка** — несколько функций с одним именем, но разными параметрами.
- **Рекурсия** — вызов функцией самой себя.

---

## 1. Объявление и определение

**Прототип (объявление):**

```cpp
int add(int a, int b);   // где-то будет определение
```

**Определение:**

```cpp
int add(int a, int b) {
    return a + b;
}
```

**Вызов:**

```cpp
int sum = add(3, 5);   // 8
```

Прототип нужен, если функция **используется до её определения**.
В заголовочных файлах (`.h`) — только прототипы. В `.cpp` — определения.

---

## 2. Возвращаемое значение

```cpp
int square(int x) { return x * x; }
double divide(double a, double b) { return a / b; }
bool is_even(int x) { return x % 2 == 0; }
```

**`void`** — функция ничего не возвращает:

```cpp
void print_hello() {
    std::cout << "Hello\n";
}
```

**`return`** завершает функцию немедленно:

```cpp
int max(int a, int b) {
    if (a > b) return a;
    return b;
}
```

**Несколько `return`** — нормально. Один `return` в конце — не обязателен.

## 3. Параметры

### По значению (по умолчанию)

```cpp
void f(int x) { x = 100; }   // изменения не видны снаружи
```

Копируется — оригинал не меняется.

### По ссылке `&`

```cpp
void inc(int& x) { ++x; }    // меняет оригинал

int a = 5;
inc(a);                      // a = 6
```

### По константной ссылке `const&`

```cpp
void print(const std::string& s) {   // не копирует, не меняет
    std::cout << s << "\n";
}
```

**Правило:**

| Что передаём | Как |
|---|---|
| Мелкие типы (int, double, char) | по значению |
| Большие объекты (string, vector) без изменений | `const&` |
| Изменяем объект | `&` |

### Указатели

```cpp
void inc_ptr(int* p) { ++(*p); }

int a = 5;
inc_ptr(&a);   // a = 6
```

Ссылки удобнее — используйте `&`, когда не нужна адресная арифметика.

## 4. Значения по умолчанию

```cpp
int power(int base, int exp = 2) {
    int result = 1;
    for (int i = 0; i < exp; ++i) result *= base;
    return result;
}

power(5);      // 25 (exp = 2)
power(2, 10);  // 1024
```

**Правило:** параметры со значениями по умолчанию идут **после**
обычных.

```cpp
void f(int a, int b = 10, int c = 20);   // ок
void g(int a = 1, int b);                // ошибка
```

## 5. Перегрузка функций

Несколько функций с одним именем, но разными параметрами:

```cpp
int add(int a, int b) { return a + b; }
double add(double a, double b) { return a + b; }
int add(int a, int b, int c) { return a + b + c; }
```

Компилятор выбирает подходящую по **числу и типам аргументов**.

**Различие только по возвращаемому типу — не перегрузка:**

```cpp
int f();
double f();   // ошибка
```

## 6. Рекурсия

Функция вызывает саму себя.

### Факториал

```cpp
long long factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}
```

**Базовый случай** (`n <= 1`) обязателен — иначе бесконечная рекурсия.

### Числа Фибоначчи

```cpp
long long fib(int n) {
    if (n <= 1) return n;
    return fib(n - 1) + fib(n - 2);
}
```

**Медленно** для больших `n` (экспоненциальная сложность). Итеративный
вариант лучше.

### Быстрая степень

```cpp
long long fast_pow(long long base, int exp) {
    if (exp == 0) return 1;
    if (exp % 2 == 0) {
        long long half = fast_pow(base, exp / 2);
        return half * half;
    }
    return base * fast_pow(base, exp - 1);
}
```

**O(log exp)** вместо **O(exp)**.

### Ханойская башня

```cpp
void hanoi(int n, char from, char to, char aux) {
    if (n == 1) {
        std::cout << from << " -> " << to << "\n";
        return;
    }
    hanoi(n - 1, from, aux, to);
    std::cout << from << " -> " << to << "\n";
    hanoi(n - 1, aux, to, from);
}
```

**Глубина рекурсии** ограничена стеком (~10⁵ вызовов обычно).
Для глубоких задач — итеративные решения или ручной стек.

## 7. Область видимости переменных

```cpp
int global = 100;   // глобальная

void f() {
    int local = 5;   // локальная — только внутри f
    global = 200;    // ок — видим глобальную
}
```

**Правила:**

- Локальные переменные видны только в своей функции.
- Глобальные — везде.
- Локальная **затеняет** глобальную с тем же именем.
- **Совет:** избегайте глобальных переменных. Передавайте параметры.

**Статические локальные:**

```cpp
void counter() {
    static int n = 0;   // сохраняется между вызовами
    ++n;
    std::cout << n << "\n";
}
```

`static` — переменная создаётся **один раз**, живёт до конца программы.

## 8. `inline`, `constexpr`, `auto`-возврат

### `inline`

Подсказка компилятору «вставить тело функции в место вызова».
Полезно для коротких функций.

```cpp
inline int square(int x) { return x * x; }
```

### `constexpr`

Функция, вычислимая на этапе компиляции:

```cpp
constexpr int square(int x) { return x * x; }

constexpr int s = square(5);   // 25 — вычислено при компиляции
int arr[square(3)];            // массив размера 9
```

### `auto` для возвращаемого типа (C++14)

```cpp
auto add(int a, int b) {
    return a + b;   // int
}
```

**Осторожно:** `auto` может вернуть **не тот тип**, что вы ожидаете.
Лучше указывать тип явно, если он неочевиден.

### Trailing return type

```cpp
auto divide(int a, int b) -> double {
    return static_cast<double>(a) / b;
}
```

## 9. Типичные задачи

### НОД (алгоритм Евклида)

```cpp
int gcd(int a, int b) {
    while (b != 0) {
        int t = b;
        b = a % b;
        a = t;
    }
    return a;
}
```

Рекурсивно:

```cpp
int gcd(int a, int b) {
    return b == 0 ? a : gcd(b, a % b);
}
```

### Проверка простого числа

```cpp
bool is_prime(int n) {
    if (n < 2) return false;
    for (int i = 2; i * i <= n; ++i) {
        if (n % i == 0) return false;
    }
    return true;
}
```

### Сумма элементов массива

```cpp
int sum(const int* arr, int size) {
    int s = 0;
    for (int i = 0; i < size; ++i) s += arr[i];
    return s;
}
```

## 10. Частые ошибки

- **Забыли `return`** — неопределённое поведение (не ошибка компиляции).
- **Забыли прототип** — «функция не найдена» при использовании до определения.
- **Параметр по значению, а хотели по ссылке** — изменения не видны снаружи.
- **Параметры по умолчанию перед обычными** — ошибка.
- **Перегрузка только по возвращаемому типу** — ошибка.
- **Бесконечная рекурсия** — нет базового случая.
- **Слишком глубокая рекурсия** — переполнение стека.
- **Изменение глобальных переменных в функции** — плохая практика.
