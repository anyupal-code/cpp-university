# Урок 10. Контрольная работа (демо-разбор)

## Цель

Разобрать типичные задачи контрольной работы: матрицы, жадные алгоритмы,
строки, простые числа, структуры + сортировка.

Каждая задача — с условием, идеей, разбором и тестами.

## Формат контрольной

Обычно 4–5 задач, 80–120 минут, без интернета, разрешён конспект.
Каждая задача оценивается в баллы; важно **решить столько, сколько успеешь**,
начиная с простых.

## Задача 1. Спираль

**Условие.** Заполнить матрицу `N × N` единицами по спирали
(начиная с верхнего левого угла по часовой стрелке). `N` — нечётное,
`1 ≤ N ≤ 50`.

**Формат ввода/вывода.** `input.txt` / `output.txt`.

**Пример (N = 7):**

```
1111111
0000001
1111101
1000101
1011101
1000001
1111111
```

**Идея.** Обходим матрицу **слоями**. На каждом слое:

1. верхняя строка → слева направо,
2. правая колонка → сверху вниз,
3. нижняя строка → справа налево,
4. левая колонка → снизу вверх.

Затем сужаем рамку и переходим к внутреннему слою.

**Сложность:** O(N²) — по числу клеток.

**Разбор** — в [task1_spiral.cpp](task1_spiral.cpp).

## Задача 2. Банкомат

**Условие.** Банкомат выдаёт сумму `S` купюрами номиналом
`5000, 2000, 1000, 500, 200, 100` рублей. Найти минимальное число купюр
или сообщить, что выдать невозможно.

**Идея — жадный алгоритм.** Идём от крупных купюр к мелким: сколько
поместится — столько берём. Для канонических наборов номиналов
(как у рубля) жадный даёт **оптимальное** решение.

```
S = 3800
5000 → 0
2000 → 1 (остаток 1800)
1000 → 1 (остаток 800)
 500 → 1 (остаток 300)
 200 → 1 (остаток 100)
 100 → 1 (остаток 0)
Итого: 5 купюр
```

**Разбор** — в [task2_atm.cpp](task2_atm.cpp).

## Задача 3. Палиндром

**Условие.** Проверить, является ли строка палиндромом. Игнорировать
регистр, пробелы и знаки препинания.

**Примеры:**

- `"A man, a plan, a canal: Panama"` → да
- `"race a car"` → нет
- `"шалаш"` → да (но с кириллицей — только ASCII в базовой версии)

**Идея — два указателя.** Левый идёт с начала, правый — с конца.
Пропускаем не-буквы, сравниваем в нижнем регистре.

```
left  →                ←  right
A man, a plan, ... Panama
```

**Разбор** — в [task3_palindrome.cpp](task3_palindrome.cpp).

## Задача 4. Решето Эратосфена

**Условие.** Найти все простые числа до `N` (включительно), `N ≤ 10⁶`.

**Идея — решето Эратосфена.**

1. Заводим массив `is_prime[0..N]`, изначально все `true`.
2. `0` и `1` — не простые.
3. Идём по `i` от 2 до √N. Если `is_prime[i]` — вычёркиваем все кратные `i`,
   начиная с `i²`.
4. Оставшиеся `true` — простые.

**Сложность:** O(N log log N) — почти линейная.

**Разбор** — в [task4_sieve.cpp](task4_sieve.cpp).

## Задача 5. Студенты

**Условие.** Дан список студентов (имя, возраст, средний балл).
Отсортировать по среднему баллу (по убыванию). При равенстве — по имени
(по возрастанию).

**Идея.** Используем `std::sort` со своим компаратором.

```cpp
std::sort(v.begin(), v.end(), [](const Student& a, const Student& b) {
    if (a.average != b.average) return a.average > b.average;
    return a.name < b.name;
});
```

**Разбор** — в [task5_students.cpp](task5_students.cpp).

## Советы к КР

1. **Читай условия дважды.** Особенно границы и формат ввода-вывода.
2. **Начинай с простых задач.** Баллы за лёгкие задачи — те же,
   что за сложные.
3. **Тестируй на границах:** `N = 1`, пустой ввод, крайние значения.
4. **Не оптимизируй преждевременно.** Сначала — работает, потом — быстро.
5. **Пиши понятно.** Даже если не успел решить — частичное решение
   может получить баллы.
