# Урок 16. Контейнеры последовательные: `vector`, `deque`, `list`

## Цель

Освоить три основных последовательных контейнера STL, понять их
различия и научиться выбирать подходящий.

## Ключевые понятия

- **Контейнер** — структура для хранения набора элементов.
- **Последовательный контейнер** — элементы хранятся в порядке добавления.
- **`std::vector`** — динамический массив.
- **`std::deque`** — двусторонняя очередь.
- **`std::list`** — двусвязный список.
- **`std::array`** — статический массив фиксированного размера.
- **Итератор** — «указатель» на элемент контейнера.

## 2. `std::vector` — динамический массив

**Что это:** непрерывный блок памяти. Как C-массив, но растёт сам.

### Создание

```cpp
#include <vector>

std::vector<int> v1;                    // пустой
std::vector<int> v2 = {1, 2, 3, 4, 5};  // с инициализацией
std::vector<int> v3(10);                // 10 нулей
std::vector<int> v4(10, 42);            // 10 элементов по 42
std::vector<int> v5(v2);                // копия
std::vector<int> v6(v2.begin(), v2.begin() + 3);  // {1, 2, 3}
```

### Основные операции

| Операция | Метод |
|---|---|
| Добавить в конец | `push_back(x)` |
| Удалить последний | `pop_back()` |
| Вставить на позицию | `insert(it, x)` |
| Удалить по итератору | `erase(it)` |
| Доступ по индексу | `v[i]` |
| Доступ с проверкой | `v.at(i)` |
| Размер | `size()` |
| Ёмкость | `capacity()` |
| Пуст? | `empty()` |
| Очистить | `clear()` |
| Резерв | `reserve(n)` |

### Пример

```cpp
std::vector<int> v;

v.push_back(10);
v.push_back(20);
v.push_back(30);

std::cout << v.size() << "\n";      // 3
std::cout << v[1] << "\n";          // 20

v.insert(v.begin() + 1, 15);        // {10, 15, 20, 30}
v.erase(v.begin() + 2);             // {10, 15, 30}

for (int x : v) std::cout << x << " ";
```

### Сильные / слабые стороны

**+** Быстрый доступ по индексу (O(1)).
**+** Хорошая кэш-локальность — быстрый обход.
**+** Минимум памяти.
**−** Вставка/удаление в середину — O(n).
**−** Вставка в начало — O(n).

**Когда использовать:** по умолчанию, если нет причин взять другое.

## 3. `std::deque` — двусторонняя очередь

**Что это:** блоки памяти. Быстрый доступ по индексу + вставка
в начало и конец — O(1).

### Создание

```cpp
#include <deque>

std::deque<int> d = {1, 2, 3};
```

### Основные операции

| Операция | Метод |
|---|---|
| Добавить в конец | `push_back(x)` |
| Добавить в начало | `push_front(x)` |
| Удалить с конца | `pop_back()` |
| Удалить с начала | `pop_front()` |
| Доступ по индексу | `d[i]`, `d.at(i)` |
| Размер | `size()` |

```cpp
std::deque<int> d;

d.push_back(20);
d.push_front(10);
d.push_back(30);
d.push_front(5);

// {5, 10, 20, 30}

std::cout << d.front() << "\n";   // 5
std::cout << d.back() << "\n";    // 30

d.pop_front();
d.pop_back();

// {10, 20}
```

**Когда использовать:**

- Нужен быстрый доступ по индексу **и** вставка/удаление с обоих концов.
- Очередь с приоритетами, буферы.
- Пример: `std::queue` по умолчанию использует `deque`.

## 4. `std::list` — двусвязный список

**Что это:** цепочка узлов, каждый хранит указатели на соседей.

### Создание

```cpp
#include <list>

std::list<int> l = {1, 2, 3};
```

### Основные операции

| Операция | Метод |
|---|---|
| Добавить в конец | `push_back(x)` |
| Добавить в начало | `push_front(x)` |
| Вставить | `insert(it, x)` |
| Удалить по итератору | `erase(it)` |
| Размер | `size()` |
| Сортировка | `sort()` |
| Слияние | `merge(other)` |
| Переместить элемент | `splice(pos, other)` |

**Нет произвольного доступа** — только через итераторы.

```cpp
std::list<int> l = {3, 1, 4, 1, 5};

l.sort();               // {1, 1, 3, 4, 5}
l.reverse();            // {5, 4, 3, 1, 1}

l.remove(3);            // удалить все 3

auto it = l.begin();
std::advance(it, 2);    // продвинуть итератор на 2
l.insert(it, 100);
```

### `splice` — перемещение без копирования

```cpp
std::list<int> a = {1, 2, 3};
std::list<int> b = {4, 5, 6};

a.splice(a.end(), b);   // a = {1, 2, 3, 4, 5, 6}, b пуст
```

Элементы **переносятся** — не копируются.

**Когда использовать:**

- Частые вставки/удаления **в середине**.
- Нужны `splice`, `merge`.
- **Редко** — `vector`/`deque` обычно лучше из-за кэш-локальности.

## 5. `std::array` — фиксированный массив

**Что это:** обёртка над C-массивом с методами STL.

```cpp
#include <array>

std::array<int, 5> arr = {1, 2, 3, 4, 5};

std::cout << arr.size() << "\n";       // 5
std::cout << arr[0] << "\n";           // 1
std::cout << arr.at(2) << "\n";        // 3

arr.fill(0);                            // всё в 0

for (int x : arr) std::cout << x << " ";
```

**Преимущества над C-массивом:**

- `.size()`, `.at()`, `.front()`, `.back()`, итераторы.
- Копируется целиком.
- Не «превращается» в указатель при передаче.

**Когда использовать:** размер известен на этапе компиляции,
нужны методы STL.

## 6. Сравнение

| Операция | `vector` | `deque` | `list` |
|---|---|---|---|
| Доступ `[i]` | O(1) | O(1) | O(n) |
| `push_back` | O(1)* | O(1) | O(1) |
| `push_front` | O(n) | O(1) | O(1) |
| `insert` в середину | O(n) | O(n) | O(1) |
| `erase` в середине | O(n) | O(n) | O(1) |
| Поиск | O(n) | O(n) | O(n) |
| Кэш-локальность | отличная | хорошая | плохая |
| Память на элемент | 1× | 1× + оверхед | 1× + 2 указателя |

\* амортизированно.

**Правило:**

- **`vector`** — по умолчанию.
- **`deque`** — если нужна вставка/удаление **с обоих концов**.
- **`list`** — если нужны **частые вставки в середину** или `splice`.
- **`array`** — если размер фиксирован и известен.

## 7. Итераторы

Все контейнеры дают итераторы:

```cpp
auto it = v.begin();       // на первый
auto ite = v.end();        // на «после последнего»

for (auto it = v.begin(); it != v.end(); ++it) {
    std::cout << *it << " ";
}

// Range-based for — то же самое короче:
for (int x : v) std::cout << x << " ";
```

**Категории итераторов:**

- **Random access** (`vector`, `deque`, `array`): `+`, `-`, `<`.
- **Bidirectional** (`list`): `++`, `--`.
- **Forward** (`forward_list`): только `++`.

Для `list` нельзя `it + 5` — только `std::advance(it, 5)`.

## 8. `size` vs `capacity` у `vector`

- **`size()`** — сколько элементов.
- **`capacity()`** — сколько поместится без перевыделения.

```cpp
std::vector<int> v;
std::cout << "size = " << v.size()
          << ", capacity = " << v.capacity() << "\n";   // 0, 0

for (int i = 1; i <= 10; ++i) {
    v.push_back(i);
    std::cout << "push_back(" << i << "): size = " << v.size()
              << ", capacity = " << v.capacity() << "\n";
}
```

**Что увидишь:** capacity растёт **удвоением**: 1, 2, 4, 8, 16.

**`reserve(n)`** — заранее выделить память:

```cpp
std::vector<int> v;
v.reserve(1000);      // capacity = 1000, size = 0
```

**Зачем:** избежать перевыделения и копирования при `push_back`.

**`shrink_to_fit()`** — уменьшить capacity до size (не гарантируется).

## 9. Типичные задачи

### Стек на `vector`

```cpp
std::vector<int> stack;
stack.push_back(1);
stack.push_back(2);
stack.push_back(3);

while (!stack.empty()) {
    std::cout << stack.back() << " ";
    stack.pop_back();
}
```

### Очередь на `deque`

```cpp
std::deque<int> q;
q.push_back(1);
q.push_back(2);
q.push_back(3);

while (!q.empty()) {
    std::cout << q.front() << " ";
    q.pop_front();
}
```

### Сортировка `list`

```cpp
std::list<int> l = {3, 1, 4, 1, 5};
l.sort();
l.unique();             // удалить подряд идущие дубликаты
```

### Удаление из `vector`

```cpp
// Удалить все чётные
std::erase_if(v, [](int x) { return x % 2 == 0; });   // C++20
```

## 10. Частые ошибки

- **`v[i]` без проверки** — UB при выходе за границы. Для проверки — `.at(i)`.
- **Изменение `vector` внутри range-based `for`** — итераторы «поедут».
- **`it + n` для `list`** — нет random access.
- **Обращение к `v[0]` у пустого `vector`** — UB. Сначала `.empty()`.
- **Забыть `reserve`** при большом числе `push_back` — лишние перевыделения.
- **`vector<bool>`** — особый случай, не совсем `vector`.
- **Итератор после `push_back`** может стать недействительным (`vector` перевыделился).
