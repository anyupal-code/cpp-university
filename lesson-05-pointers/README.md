# Урок 5. Введение в указатели. Арифметика указателей

## Цель

Понять, что такое указатели, как они связаны с памятью и массивами,
и научиться пользоваться ими безопасно.

## Ключевые понятия

- **Указатель** — переменная, хранящая **адрес** другой переменной.
- **`&`** — оператор «взять адрес».
- **`*`** — оператор «разыменовать» (получить значение по адресу).
- **`nullptr`** — «нулевой» указатель, никуда не указывает (C++11).
- **Арифметика указателей** — `p + n`, `p - n`, `p[i]`, `p - q`.
- **Разыменование `nullptr`** — UB (программа падает).

---

## 1. Что такое указатель

Переменная хранится в памяти по **адресу**. Указатель — это переменная,
которая хранит **адрес** другой переменной.

```
Переменная x = 42     →  адрес 0x7ffee4c0
Указатель p = &x      →  значение p = 0x7ffee4c0
*p                    →  42
```

```cpp
int x = 42;
int* p = &x;         // p хранит адрес x

std::cout << x  << "\n";    // 42
std::cout << &x << "\n";    // адрес, например 0x7ffee4c0
std::cout << p  << "\n";    // тот же адрес
std::cout << *p << "\n";    // 42 — значение по адресу
```

---

## 2. Объявление указателей

```cpp
int*    p1;    // указатель на int
double* p2;    // указатель на double
char*   p3;    // указатель на char
```

**Звёздочку можно писать:**

- `int* p;` — звёздочка у типа (рекомендуется).
- `int *p;` — звёздочка у переменной.

При объявлении нескольких указателей в одной строке:

```cpp
int* a, * b;    // оба указатели
int* a, b;      // a — указатель, b — int (!)
```

**Правило:** объявляйте указатели по одному на строку.

---

## 3. `nullptr` и `NULL`

**`nullptr`** (C++11) — «нулевой указатель»:

```cpp
int* p = nullptr;

if (p == nullptr) {
    std::cout << "p никуда не указывает\n";
}
```

**`NULL`** — старый макрос (`0`). **Не используйте**, только `nullptr`.

**Правило:** инициализируйте указатели либо адресом, либо `nullptr`.
Не оставляйте «диких» указателей.

---

## 4. Разыменование

**`*p`** — получить значение по адресу:

```cpp
int x = 42;
int* p = &x;

std::cout << *p << "\n";   // 42

*p = 100;                  // изменить x через указатель
std::cout << x << "\n";    // 100
```

**Разыменование `nullptr` — падение:**

```cpp
int* p = nullptr;
*p = 5;      // UB: segmentation fault
```

**Правило:** перед разыменованием проверяйте `p != nullptr`,
если не уверены.

---

## 5. Указатель vs значение

```cpp
void by_value(int x) {        // копия
    x = 100;
}

void by_pointer(int* p) {     // адрес
    *p = 100;
}

int a = 5;

by_value(a);        // a = 5
by_pointer(&a);     // a = 100
```

**Ссылки (`&`) удобнее** для этой цели. Указатели нужны, когда:

- нужно «ничего не передавать» (`nullptr`),
- нужна арифметика указателей,
- работаем с C-API.

## 6. Указатели и массивы

**Имя массива — адрес его первого элемента:**

```cpp
int arr[5] = {10, 20, 30, 40, 50};

int* p = arr;      // = &arr[0]
std::cout << *p << "\n";      // 10
std::cout << p[2] << "\n";    // 30
std::cout << *(p + 2) << "\n"; // 30
```

**Эквивалентности:**

| Запись | Эквивалент |
|---|---|
| `arr[i]` | `*(arr + i)` |
| `p[i]` | `*(p + i)` |
| `arr` | `&arr[0]` |

**Внимание:** `sizeof(arr)` даёт **размер массива**, а `sizeof(p)` — **размер указателя** (8 байт). Информация о размере массива через указатель **теряется**.

---

## 7. Арифметика указателей

Указатель можно двигать:

```cpp
int arr[5] = {10, 20, 30, 40, 50};
int* p = arr;

std::cout << *p       << "\n";   // 10
std::cout << *(p + 1) << "\n";   // 20
std::cout << *(p + 4) << "\n";   // 50

++p;                             // теперь p указывает на arr[1]
std::cout << *p << "\n";         // 20
```

**Разница указателей:**

```cpp
int* p1 = &arr[0];
int* p2 = &arr[3];
std::ptrdiff_t diff = p2 - p1;   // 3 — сколько элементов между
```

**Важно:** `p + 1` **не сдвигает на 1 байт**, а сдвигает
на `sizeof(int)` = 4 байта. Это ключевое отличие арифметики указателей
от обычной арифметики.

```cpp
std::cout << (void*)p       << "\n";   // адрес
std::cout << (void*)(p + 1) << "\n";   // адрес + 4
```

## 8. `const` и указатели

Три разных комбинации:

### `const int* p` — указатель на константу

```cpp
int x = 5, y = 10;
const int* p = &x;

*p = 100;      // ошибка: значение менять нельзя
p = &y;        // ок: можно перевести на другую переменную
```

### `int* const p` — константный указатель

```cpp
int x = 5, y = 10;
int* const p = &x;

*p = 100;      // ок: значение можно менять
p = &y;        // ошибка: нельзя перевести
```

### `const int* const p` — и то, и другое

```cpp
const int* const p = &x;

*p = 100;      // ошибка
p = &y;        // ошибка
```

**Мнемоника:** читайте справа налево.

- `const int* p` — `p` указатель на `const int`.
- `int* const p` — `p` константный указатель на `int`.

## 9. Указатели на функции (кратко)

```cpp
int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }

int main() {
    int (*op)(int, int) = add;

    std::cout << op(5, 3) << "\n";   // 8
    op = sub;
    std::cout << op(5, 3) << "\n";   // 2
}
```

Используется для **обратных вызовов** (callbacks), стратегий, сортировок.
Подробнее — в STL и алгоритмах.

---

## 10. Опасности

| Опасность | Что происходит |
|---|---|
| Разыменование `nullptr` | Падение (segfault) |
| Разыменование «дикого» указателя | Непредсказуемо |
| Выход за границы массива | Чтение/запись чужой памяти |
| Забыли `delete` (для `new`) | Утечка памяти |
| Двойный `delete` | UB |
| Возврат указателя на локальную переменную | Висячий указатель |

**Пример висячего указателя:**

```cpp
int* bad() {
    int local = 5;
    return &local;   // local умрёт после return — UB
}
```

**Правило:** не возвращайте указатели на локальные переменные.

## 11. Типичные задачи

### Обмен двух значений через указатели

```cpp
void swap(int* a, int* b) {
    int t = *a;
    *a = *b;
    *b = t;
}
```

### Сумма массива через указатель

```cpp
int sum(int* arr, int n) {
    int s = 0;
    for (int i = 0; i < n; ++i) s += arr[i];
    return s;
}
```

### Обход строки C-стиля

```cpp
void print(const char* s) {
    while (*s != '\0') {
        std::cout << *s;
        ++s;
    }
}
```

## 12. Частые ошибки

- **Разыменование без проверки** `nullptr`.
- **Путаница `*p = ...` и `p = ...`** — первое меняет значение,
  второе — куда указывает.
- **`sizeof(arr)` через указатель** — теряется размер массива.
- **Забыли `&`** при передаче в функцию, ожидающую указатель.
- **Возврат указателя на локальную переменную** — висячий указатель.
- **Путаница `const int*` и `int* const`**.
- **Арифметика на `nullptr`** — UB.
