# Урок 9. Структуры. Введение в ООП

## Цель

Понять, как объединять связанные данные в один тип, освоить структуры
(`struct`), перечисления (`enum` / `enum class`) и первые методы внутри
структуры.

## Ключевые понятия

- **Структура (`struct`)** — пользовательский тип, объединяющий поля.
- **Поле** — переменная внутри структуры.
- **Метод** — функция внутри структуры (в C++ структура может иметь методы).
- **`enum` / `enum class`** — перечисление именованных констант.
- **Конструктор** — функция, вызываемая при создании объекта.
- **Инкапсуляция** — сокрытие деталей реализации (подробно — в уроке 11).

---

## 1. Объявление структуры

```cpp
struct Point {
    int x;
    int y;
};
```

- **`struct`** — ключевое слово.
- **Поля** — как обычные переменные внутри.
- **`;`** после `}` — обязательна (в отличие от функций).

### Создание и использование

```cpp
Point p;              // поля не инициализированы
p.x = 3;
p.y = 5;

Point q{1, 2};        // агрегатная инициализация
Point r = {10, 20};   // то же
```

**Доступ к полям:** `объект.поле`.

---

## 2. Инициализация

```cpp
Point a{1, 2};           // x=1, y=2
Point b{1};              // x=1, y=0 (C++11+)
Point c{};               // x=0, y=0
Point d = {5, 10};       // равно-инициализация
```

**Значения по умолчанию в структуре:**

```cpp
struct Point {
    int x = 0;
    int y = 0;
};

Point p;        // x=0, y=0
Point q{3};     // x=3, y=0
```

## 3. Функции и структуры

### Структура как параметр

```cpp
void print(const Point& p) {
    std::cout << "(" << p.x << ", " << p.y << ")\n";
}
```

**Правило:** большие структуры — **по константной ссылке** `const&`,
чтобы не копировать.

### Изменение структуры

```cpp
void move(Point& p, int dx, int dy) {
    p.x += dx;
    p.y += dy;
}
```

Без `&` изменения не сохранятся (копия).

### Возврат структуры

```cpp
Point make_point(int x, int y) {
    return {x, y};        // C++11+
}
```

## 4. Массив структур

```cpp
Point points[3] = {
    {1, 2},
    {3, 4},
    {5, 6}
};

for (const auto& p : points) {
    std::cout << "(" << p.x << ", " << p.y << ")\n";
}
```

**`std::vector` структур:**

```cpp
std::vector<Point> v;
v.push_back({1, 2});
v.push_back({3, 4});

for (const auto& p : v) {
    std::cout << p.x << " " << p.y << "\n";
}
```

## 5. Методы внутри структуры

В C++ `struct` может содержать **функции**:

```cpp
struct Point {
    int x = 0;
    int y = 0;

    void print() const {
        std::cout << "(" << x << ", " << y << ")\n";
    }

    double length() const {
        return std::sqrt(x * x + y * y);
    }

    void move(int dx, int dy) {
        x += dx;
        y += dy;
    }
};
```

Использование:

```cpp
Point p{3, 4};
p.print();          // (3, 4)
std::cout << p.length() << "\n";   // 5

p.move(1, 1);       // изменяет p
p.print();          // (4, 5)
```

### `const` в методах

**`void print() const`** — метод **не меняет** объект.

**Правило:** если метод не меняет поля — помечайте `const`.
Это позволяет вызывать его у константных объектов.

```cpp
void f(const Point& p) {
    p.print();      // ok: print() const
    // p.move(1,1); // ошибка: move() не const
}
```

## 6. Конструкторы

**Конструктор** вызывается при создании объекта.

```cpp
struct Point {
    int x, y;

    // Конструктор по умолчанию
    Point() : x(0), y(0) {}

    // Конструктор с параметрами
    Point(int x, int y) : x(x), y(y) {}
};
```

**Список инициализации `: x(x), y(y)`** — инициализирует поля **до** тела
конструктора. Это **правильный** способ, эффективнее присваивания в теле.

**Использование:**

```cpp
Point p1;              // Point()
Point p2{3, 5};        // Point(3, 5)
Point p3 = Point(1, 2);
```

## 7. `enum` — перечисления

**Обычный `enum`:**

```cpp
enum Color {
    RED,
    GREEN,
    BLUE
};

Color c = RED;
```

- `RED = 0`, `GREEN = 1`, `BLUE = 2` — автоматически.
- Можно задать значения: `RED = 10`.
- **Проблема:** имена **попадают в общую область видимости** —
  конфликт с другими именами.

**`enum class` (C++11) — рекомендуется:**

```cpp
enum class Color {
    Red,
    Green,
    Blue
};

Color c = Color::Red;

if (c == Color::Red) {
    std::cout << "Красный\n";
}
```

- Имена **не попадают** в общую область видимости — обращение через `Color::`.
- **Строгая типизация** — нельзя смешивать с `int` без явного приведения.
- **Рекомендуется в современном C++.**
- Под капотом — целое число.
- Преобразование в число: `static_cast<int>(c)`.
- **C++23:** `std::to_underlying(c)` — то же, читается лучше.

```cpp
#include <utility>

auto value = std::to_underlying(Color::Red);   // 0
```

## 8. Когда использовать `struct`

**Когда:**

- Набор связанных данных (точка, дата, RGB, координаты).
- Конфигурация (настройки, параметры).
- Возврат нескольких значений из функции.
- Простая «запись» (record) — данные + минимум поведения.

**Когда НЕ использовать:**

- Если нужна **сложная логика** — лучше класс (следующие уроки).
- Если нужно **наследование, полиморфизм** — класс (уроки 21+).

**Разница `struct` и `class` в C++:**

| Свойство | `struct` | `class` |
|---|---|---|
| Доступ по умолчанию | `public` | `private` |
| Наследование по умолчанию | `public` | `private` |

**Функционально — одно и то же.** Разница только в стиле:

- `struct` — для простых «данных».
- `class` — для полноценных объектов.

## 9. Типичные задачи

### Структура «Точка»

```cpp
struct Point {
    double x = 0;
    double y = 0;

    double length() const {
        return std::sqrt(x * x + y * y);
    }
};
```

### Структура «Студент»

```cpp
struct Student {
    std::string name;
    int age = 0;
    double average = 0.0;

    void print() const {
        std::cout << name << ", " << age
                  << " лет, средний " << average << "\n";
    }
};
```

### Массив студентов

```cpp
std::vector<Student> group = {
    {"Иван", 18, 4.5},
    {"Мария", 19, 4.8},
    {"Пётр", 18, 4.2}
};

for (const auto& s : group) {
    s.print();
}
```

### Возврат нескольких значений

```cpp
struct MinMax {
    int min;
    int max;
};

MinMax find_min_max(const std::vector<int>& v) {
    return {*std::min_element(v.begin(), v.end()),
            *std::max_element(v.begin(), v.end())};
}

int main() {
    auto [mn, mx] = find_min_max({3, 1, 4, 1, 5, 9, 2, 6});
    std::cout << "min = " << mn << ", max = " << mx << "\n";
}
```

**Структурированная привязка** (`auto [mn, mx] = ...`) — C++17.

## 10. Частые ошибки

- **Забыли `;` после `}` структуры.**
- **Не инициализировали поля** — мусор в памяти.
- **Передача структуры по значению** большого размера — копирование.
- **Метод без `const`**, хотя он не меняет объект — не вызывается у константного объекта.
- **Обычный `enum` вместо `enum class`** — конфликты имён.
- **Присваивание `enum class` к `int`** без `static_cast`.
- **Путаница порядка полей** при агрегатной инициализации.
