# Урок 28. Разбор демо экзамена

## Цель

Разобрать 6 задач, охватывающих весь курс: контейнеры, алгоритмы,
ООП, полиморфизм, RAII, умные указатели.

## Формат

Задачи **комплексные** — каждая требует нескольких тем сразу.
Это финальная проверка: умеешь ли применять всё вместе.

---

## Задача 1. Анализ текста

**Условие.** Дан текст. Найти:

1. Топ-5 самых частых слов.
2. Слова, встречающиеся только один раз.
3. Самую длинную цепочку слов, начинающихся с одной буквы.

**Что тренирует:**

- `unordered_map` для частот.
- `set` для уникальных.
- Сортировка и `partial_sort` для топа.
- Работа со строками.

**Разбор** — в [task_word_analysis.cpp](task_word_analysis.cpp).

---

## Задача 2. Операции над матрицей

**Условие.** Реализовать класс `Matrix`:

- Конструктор `(rows, cols)`, заполнение нулями.
- `operator()` для доступа `m(i, j)`.
- `operator+` — сложение матриц.
- `operator*` — умножение матриц.
- `transpose()` — транспонирование.
- `operator<<` — вывод.

**Что тренирует:**

- Классы, конструкторы, операторы.
- Работа с двумерными данными.
- Проверка размеров.

**Разбор** — в [task_matrix_ops.cpp](task_matrix_ops.cpp).

---

## Задача 3. Иерархия фигур с полиморфизмом

**Условие.** Реализовать:

- Абстрактный `Shape` с `area()`, `perimeter()`, `name()`.
- `Circle`, `Rectangle`, `Triangle`, `RegularPolygon`.
- `operator<<` для вывода.
- Функция `analyze(vector<unique_ptr<Shape>>)` — общая площадь,
  максимум, сортировка по площади.
- `clone()` — глубокое копирование через виртуальный метод.

**Что тренирует:**

- Абстрактные классы и чистая виртуальность.
- Полиморфная коллекция.
- Виртуальный `clone` (паттерн «Prototype»).
- Перегрузка `<<`.

**Разбор** — в [task_shapes_hierarchy.cpp](task_shapes_hierarchy.cpp).

---

## Задача 4. Текстовый редактор

**Условие.** Реализовать класс `TextEditor`:

- `insert(text)` — добавить в конец.
- `undo()` — отменить последнее действие.
- `redo()` — вернуть отменённое.
- `print()` — вывести текущий текст.
- Ограничение истории — последние 100 действий.

**Что тренирует:**

- `std::stack` (или `vector`) для undo/redo.
- RAII и классы.
- Работа со строками.

**Разбор** — в [task_text_editor.cpp](task_text_editor.cpp).

---

## Задача 5. Библиотека

**Условие.** Реализовать систему «библиотека»:

- `Book` — название, автор, год, ISBN.
- `Library` — хранит книги через `unique_ptr`.
- Методы:
  - `add_book`,
  - `find_by_author`,
  - `find_by_year_range`,
  - `remove_by_isbn`,
  - `sort_by_title`,
  - `total_books`.
- Сохранение/загрузка в текстовый файл.

**Что тренирует:**

- Классы и коллекции.
- `unordered_map` для индексов.
- Сортировка объектов.
- Файлы (`fstream`).
- Умные указатели.

**Разбор** — в [task_library.cpp](task_library.cpp).

---

## Задача 6. LRU-кэш

**Условие.** Реализовать кэш «Least Recently Used»:

- Фиксированная ёмкость `N`.
- `get(key)` — вернуть значение или -1.
- `put(key, value)` — добавить/обновить.
- При переполнении удаляется **самый давно использованный**.
- Все операции — O(1).

**Что тренирует:**

- Комбинация `unordered_map` + `list`.
- Итераторы и их связь.
- Классическая задача на собеседованиях.

**Разбор** — в [task_lru_cache.cpp](task_lru_cache.cpp).

| 1. Анализ текста | `map`, `set`, сортировка |
| 2. Матрица | классы, операторы, двумерные данные |

## Советы к экзамену

1. **Читай условие дважды.** Особенно граничные случаи.
2. **Начинай с простых задач.** Баллы — те же.
3. **Пиши чисто.** Компилируй часто.
4. **Используй STL.** Не изобретай `vector` вручную.
5. **Тестируй на границах:** пустой ввод, один элемент, максимум.
6. **Не оптимизируй преждевременно.** Сначала работает — потом быстро.
7. **Управляй временем.** 90 минут на 5–6 задач — примерно 15 минут на задачу.
