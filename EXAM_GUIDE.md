### Модуль 1. Основы языка

**1. [Введение. Первая программа](lesson-01-intro/README.md)**
*   `#include <iostream>` — для ввода-вывода. `main()` — точка входа, возвращает `int`.
*   `std::cout <<` — вывод, `std::cin >>` — ввод. `std::endl` — перевод строки + сброс буфера.

**2. [Память и типы данных](lesson-02-memory-types/README.md)**
*   `sizeof` — размер в байтах. `int` (4), `double` (8), `char` (1).
*   **Переполнение:** `unsigned` идёт по кругу, `signed` — Undefined Behavior (UB).
*   **IEEE 754:** `float` (32 бита), `double` (64 бита). `0.1 + 0.2 != 0.3`. Сравнивать с точностью `eps`.
*   **Биты:** `&` (И), `|` (ИЛИ), `^` (XOR), `~` (НЕ), `<<` (умножение на 2^n), `>>` (деление).

**3. [Условия и циклы](lesson-03-control-flow/README.md)**
*   `if / else if / else`. `switch` — только для целых и `char`. Не забудь `break`.
*   Циклы: `for` (известно кол-во), `while` (условие до), `do-while` (условие после).
*   `break` — выход из цикла, `continue` — пропуск итерации.

**4. [Функции и рекурсия](lesson-04-functions/README.md)**
*   Перегрузка — одно имя, разные параметры.
*   Параметры: по значению (копия), по ссылке `&` (меняем), по `const&` (не копируем, не меняем — по умолчанию).
*   Рекурсия требует **базовый случай** (выход). Ограничена глубиной стека.

### Модуль 2. Указатели и память

**5. [Указатели. Арифметика](lesson-05-pointers/README.md)**
*   `&x` — взять адрес, `*p` — разыменовать (получить значение).
*   `nullptr` — пустой указатель. Разыменование `nullptr` — падение программы.
*   Имя массива — это указатель на первый элемент. `arr[i] == *(arr + i)`.

**6. [Висячие указатели, RAII, умные указатели](lesson-06-memory-safety/README.md)**
*   `new` / `delete` (и `new[]` / `delete[]` для массивов).
*   **Висячий указатель** — после `delete` использовать нельзя. Обнуляй: `p = nullptr`.
*   **Утечка** — `new` без `delete`.
*   **RAII** — ресурс в конструкторе, освобождение в деструкторе.

**7. [Массивы. Векторы (`std::vector`)](lesson-07-arrays/README.md)**
*   C-массив: фиксированный размер, нет проверки границ.
*   `vector`: динамический. `push_back`, `size`, `capacity`. `capacity` растёт удвоением.
*   `at()` — с проверкой границ (бросает исключение), `[]` — без проверки.

**8. [Строки. Файлы](lesson-08-2d-strings-files/README.md)**
*   `std::string`: `size`, `find`, `substr`, `replace`.
*   `std::getline` — читать с пробелами (после `cin >>` нужен `cin.ignore()`).
*   Файлы: `std::ifstream` (чтение) / `std::ofstream` (запись). Закрываются автоматически (RAII).

### Модуль 3. ООП (Объектно-ориентированное программирование)

**9. [Структуры. `enum class`](lesson-09-structs-oop-intro/README.md)**
*   `struct` — набор полей (по умолчанию `public`).
*   `enum class` — строгий тип (обращение через `Color::Red`). Обычный `enum` льёт имена в общую область.

**11. [Классы. Конструкторы. Перегрузка операторов](lesson-11-classes/README.md)**
*   `class` — по умолчанию `private`. Инкапсуляция: `private`, `protected`, `public`.
*   Конструктор (создаёт), деструктор `~` (удаляет). Список инициализации `: x_(x)`.
*   Перегрузка операторов: `operator+`, `operator<<` (вне класса), `operator[]`.
*   `explicit` — запрет неявного преобразования (для конструкторов с 1 параметром).

**12. [Передача объектов. Коллекции](lesson-12-objects-collections/README.md)**
*   Копирование по значению, передача по `const&` (основной способ).
*   `std::map` / `std::unordered_map` — словари. `std::sort` — сортировка (компаратор — строгий `<`!).

**13. [Исключения. RAII. Правило пяти](lesson-13-exceptions-raii/README.md)**
*   `try` / `catch (const std::exception& e)` / `throw`.
*   Порядок `catch` — от частных к общим. `catch(...)` — в конце.
*   **Правило трёх/пяти:** деструктор, копирование, присваивание, move-конструктор, move-присваивание.
*   **`noexcept`** — на move-операциях (иначе `vector` будет копировать).

**14. [Умные указатели](lesson-14-smart-pointers/README.md)**
*   `unique_ptr` — один владелец. Только `std::move`. `make_unique`.
*   `shared_ptr` — общий владелец (счётчик ссылок). `make_shared`.
*   `weak_ptr` — слабая ссылка. Нужна для разрыва **циклов** в `shared_ptr` (иначе утечка).

**15. [Move-семантика](lesson-15-move-semantics/README.md)**
*   lvalue (имеет имя) vs rvalue (временное).
*   `std::move` **не двигает**, а разрешает move (кастует в rvalue).
*   После `std::move` объект в «перемещённом состоянии» (использовать нельзя).

### Модуль 4. STL и Наследование

**16-18. [Контейнеры (`vector`, `map`, `set`)](lesson-16-sequence-containers/README.md)**
*   `vector` — динамический массив (по умолчанию).
*   `map` / `set` — красно-чёрное дерево (O(log n), отсортировано).
*   `unordered_map` / `unordered_set` — хеш-таблица (O(1), порядок не важен).
*   `map` опасен: `m[key]` создаёт элемент, если его нет. Для чтения — `find()` или `at()`.

**19. [Алгоритмы STL](lesson-19-stl-algorithms/README.md)**
*   `sort`, `find`, `count`, `min_element`, `max_element`.
*   **Лямбды:** `[](int a, int b) { return a > b; }`.
*   `ranges` (C++20): `views::filter`, `views::transform` (ленивые вычисления).

**21. [Наследование](lesson-21-inheritance-basic/README.md)**
*   **Порядок:** конструкторы Base → Derived, деструкторы Derived → Base.
*   **Виртуальный деструктор** (`virtual ~Base() = default;`) **ОБЯЗАТЕЛЕН** для полиморфного базового класса.
*   **Срезка (Slicing):** копирование наследника в переменную базового типа (теряются данные). Передавай по ссылке/указателю.

**22. [Полиморфизм. RTTI. Касты](lesson-22-inheritance-rtti/README.md)**
*   `virtual` — вызов по фактическому типу (через указатель/ссылку). Пиши `override` для проверки.
*   `dynamic_cast` — безопасное приведение вниз (нужен `virtual`). При ошибке — `nullptr`.
*   `static_cast` — быстрый, но без проверки. `const_cast` — снять `const`. `reinterpret_cast` — переинтерпретация битов.
*   `typeid` — точный тип (`typeid(*p).name()`).

**25-26. [Абстрактные классы и интерфейсы](lesson-25-abstract-classes/README.md)**
*   **Чистая виртуальная функция** `virtual void f() = 0;` — делает класс абстрактным.
*   Абстрактный класс: объект создать нельзя, указатель — можно.
*   **Интерфейс** — абстрактный класс без полей (только чистые виртуальные).
*   Класс может реализовать **несколько интерфейсов** (множественное наследование интерфейсов).

### Модуль 5. Продвинутое

**20, 23, 24, 27, 28. [Практика: ДП, шаблоны, касты, разбор задач](lesson-28-exam-demo/README.md)**
*   **Шаблоны:** `template <typename T>`. Работают с любым типом (`vector`, `map` построены на них).
*   **Динамическое программирование:** мемоизация (сохранение результатов в массив/`map`), чтобы не считать дважды (пример: Фибоначчи).
*   **Указатели на функции:** `int (*func)(int, int)`. `std::function` — более удобная обёртка.
*   **Правило:** используй `vector`/`unique_ptr` вместо сырых `new`/`delete` (Правило нуля).

### Итог: 10 заповедей программиста на C++

1. Всегда инициализируй переменные.
2. Ставь `virtual` деструктор в базовом классе полиморфной иерархии.
3. Пиши `override` при переопределении методов.
4. Не используй `new`/`delete` вручную без необходимости (RAII!).
5. Move-операции должны быть `noexcept`.
6. Компаратор для `sort` — только строгий `<`.
7. `map[key]` создаёт элемент — для чтения используй `find()`.
8. `const &` — лучший способ передачи параметров (без копии и изменений).
9. `std::move` не двигает, а разрешает move.
10. После `std::move` объект нельзя использовать.
